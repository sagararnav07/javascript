Here are 20 basic JavaScript questions that can help you build logic and improve your problem-solving skills:

### 1. **FizzBuzz Problem**
   - Write a program that prints the numbers from 1 to 100. For multiples of 3, print "Fizz" instead of the number, and for the multiples of 5, print "Buzz". For numbers which are multiples of both 3 and 5, print "FizzBuzz".

### 2. **Reverse a String**
   - Write a function that takes a string as input and returns the string in reverse order.
   - Example: `reverseString("hello")` should return `"olleh"`.

### 3. **Check for Palindrome**
   - Write a function to check if a given string is a palindrome (reads the same forward and backward).
   - Example: `isPalindrome("madam")` should return `true`.

### 4. **Find the Largest Number in an Array**
   - Write a function that takes an array of numbers and returns the largest number.
   - Example: `findLargest([1, 5, 3, 9, 2])` should return `9`.

### 5. **Factorial of a Number**
   - Write a function to calculate the factorial of a given number.
   - Example: `factorial(5)` should return `120`.

### 6. **Find the Fibonacci Sequence**
   - Write a function to generate the first `n` numbers in the Fibonacci sequence.
   - Example: `fibonacci(5)` should return `[0, 1, 1, 2, 3]`.

### 7. **Sum of All Numbers in an Array**
   - Write a function that takes an array of numbers and returns the sum of all the numbers.
   - Example: `sumArray([1, 2, 3, 4, 5])` should return `15`.

### 8. **Check for Prime Number**
   - Write a function that checks if a given number is a prime number.
   - Example: `isPrime(7)` should return `true`.

### 9. **Count Vowels in a String**
   - Write a function that counts the number of vowels in a given string.
   - Example: `countVowels("hello world")` should return `3`.

### 10. **Find the Second Largest Number in an Array**
   - Write a function that returns the second largest number in an array.
   - Example: `secondLargest([10, 5, 8, 1, 9])` should return `9`.

### 11. **Remove Duplicates from an Array**
   - Write a function that removes duplicate values from an array.
   - Example: `removeDuplicates([1, 2, 2, 3, 4, 4, 5])` should return `[1, 2, 3, 4, 5]`.

### 12. **Find the Intersection of Two Arrays**
   - Write a function that returns the intersection (common elements) of two arrays.
   - Example: `intersection([1, 2, 3], [2, 3, 4])` should return `[2, 3]`.

### 13. **Find the Missing Number in a Sequence**
   - Write a function that finds the missing number in an array that contains a sequence of numbers in order.
   - Example: `findMissing([1, 2, 4, 5])` should return `3`.

### 14. **Check if Two Strings are Anagrams**
   - Write a function to determine if two strings are anagrams (contain the same characters in a different order).
   - Example: `isAnagram("listen", "silent")` should return `true`.

### 15. **Flatten a Nested Array**
   - Write a function to flatten a nested array (an array that contains other arrays).
   - Example: `flatten([1, [2, 3], [4, [5, 6]]])` should return `[1, 2, 3, 4, 5, 6]`.

### 16. **Convert Celsius to Fahrenheit**
   - Write a function to convert a temperature from Celsius to Fahrenheit.
   - Example: `celsiusToFahrenheit(0)` should return `32`.

### 17. **Check if a Number is Even or Odd**
   - Write a function to check if a given number is even or odd.
   - Example: `isEven(4)` should return `true`.

### 18. **Find the GCD of Two Numbers**
   - Write a function to find the greatest common divisor (GCD) of two numbers.
   - Example: `gcd(8, 12)` should return `4`.

### 19. **Capitalize the First Letter of Each Word in a String**
   - Write a function that capitalizes the first letter of each word in a string.
   - Example: `capitalizeWords("hello world")` should return `"Hello World"`.

### 20. **Merge Two Sorted Arrays**
   - Write a function that merges two sorted arrays into one sorted array.
   - Example: `mergeArrays([1, 3, 5], [2, 4, 6])` should return `[1, 2, 3, 4, 5, 6]`.

These questions will help you practice basic JavaScript concepts and improve your logical thinking and problem-solving abilities.
